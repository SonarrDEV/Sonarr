## 🚀 About the Project

**Sonarr** is a PVR for Usenet and BitTorrent users. It can monitor multiple RSS feeds for new episodes of your favorite shows and will grab, sort, and rename them. It can also be configured to automatically upgrade the quality of files already downloaded when a better quality format becomes available (e.g., from DVD to Blu-Ray).

---

## ✨ Key Features

| Category | Feature Description |
| :--- | :--- |
| **🔍 Monitoring** | Automatically detects new episodes and scans your library to download missing ones. |
| **📈 Quality Upgrades** | Watches for better quality versions of episodes you already own and upgrades them automatically. |
| **🛡️ Reliability** | Automatic failed download handling will try another release if one fails. |
| **📁 Organization** | Fully configurable episode renaming and directory structuring. |
| **🔗 Integrations** | Full integration with download clients and media servers (*SABnzbd, NZBGet, Plex, Kodi, etc.*). |
